# MediaPipe Task Bundles

This directory contains Google MediaPipe Tasks vision model bundles used by SETU for real-time keypoint extraction.

## Files
- `holistic_landmarker.task`: Google MediaPipe Holistic Landmarker bundle (Face, Pose, Left Hand, Right Hand).
  - Version: MediaPipe Tasks 0.10.x
  - Origin: Google AI Edge (https://github.com/google-ai-edge/mediapipe)
  - Purpose: Real-time 3D landmark extraction for Hands and Pose
  - Status: Stored locally; ignored by Git due to binary file size (~13 MB).
