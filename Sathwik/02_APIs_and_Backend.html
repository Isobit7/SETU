APIs, Backend Architecture & WebSocket Protocol

Comprehensive inventory of route definitions, distinct URL paths and aliases, binary WebSocket streaming contracts, and server telemetry.

1. Endpoint Architecture: Route Definitions vs. URL Paths

To ensure strict architectural precision, SETU distinguishes the number of unique Python route handler functions from the number of distinct URL path routes, accounting for dual route aliases provided for backward compatibility and low-latency client access.

16 Handler Functions

Independent Python async functions handling requests across main.py, predict.py, models.py, video.py, dataset.py, and websocket/recognize.py.

21 Distinct URL Paths

The total set of reachable HTTP and WebSocket route patterns, including root, API version prefixes (/api/v1/), and alias paths.

2 Dedicated Aliases

/health ↔ /api/health (Health check alias) and /ws/recognize ↔ /api/v1/ws/recognize (Streaming WebSocket alias).

3. Real-Time WebSocket Streaming Protocol

Live sign language recognition requires sub-50ms latency. SETU uses persistent full-duplex WebSocket connections routed to backend/app/websocket/recognize.py via two paths: WS /api/v1/ws/recognize and WS /ws/recognize (alias).

3.1. Ingress Message Types

  • Binary Message (Raw JPEG Bytes): Client rasterizes webcam frames onto an offscreen HTML5 canvas, encodes them as JPEG chunks, and sends raw byte buffers.
  • Text Message (JSON Control Actions): The server accepts real-time control actions without interrupting video streaming:
Action Name JSON Command Payload Backend Handler Behavior
reset {"action": "reset"} Flushes rolling FIFO buffers, resets MediaPipe landmark filters, and clears sentence state.
clear_sentence {"action": "clear_sentence"} Clears accumulated words and translated text from SentenceAccumulator.
backspace {"action": "backspace"} Removes the last committed word or letter from the accumulated sentence buffer.
set_model {"action": "set_model", "model": "realsign"} Hot-swaps active inference classifier (realsign, isl_mvp, isl_sequence_lstm, include_stream).
set_threshold {"action": "set_threshold", "threshold": 0.45} Dynamically alters confidence gating threshold (bounded between 0.10 and 0.95).
set_object_detection {"action": "set_object_detection", "enabled": false} Toggles the background YOLO-World v2 worker thread to reduce compute on battery-constrained devices.
resolve_disambiguation {"action": "resolve_disambiguation", "selected": "O"} Commits user choice when low confidence margin prompts a disambiguation HUD overlay.
accept_prediction {"action": "accept_prediction", "phrase": "WATER"} Commits auto-complete predictive vocabulary phrase directly into the sentence buffer.

4. Core Data Schemas & Models

SETU validates all incoming REST requests using Pydantic v2 schemas in backend/app/schemas/predict.py:

Python (Pydantic v2) • backend/app/schemas/predict.py 
class LandmarkRequest(BaseModel):
    """Payload for hand landmark prediction supporting single-hand and dual-hand ISL."""
    features: Optional[List[float]] = Field(
        default=None,
        description="Normalized feature vector: 126-D dual-hand (recommended), 89-D, or 63-D"
    )
    landmarks: Optional[List[Dict[str, float]]] = Field(
        default=None,
        description="21 primary hand landmarks, each with 'x', 'y', and optional 'z'"
    )
    secondary_landmarks: Optional[List[Dict[str, float]]] = Field(
        default=None,
        description="21 secondary hand landmarks for bimanual ISL letters (B, D, P, Q, T)"
    )
    dominant_hand: Optional[str] = Field(default="right")

class PredictionResponse(BaseModel):
    """Structured response from sign language classifier."""
    letter: str = Field(description="Top-ranked alphabet letter (A-Z)")
    confidence: float = Field(description="Confidence of top-ranked letter")
    top_3: List[TopCandidate] = Field(description="Top 3 predicted candidates")

5. Lifecycle Management & Observability

5.1. Lifespan Startup & Warmup

In backend/app/main.py:lifespan, the server utilizes FastAPI's @asynccontextmanager lifecycle:

  • Eager Neural Warmup: Instantiates classifier_service and loads realsign_26class_mlp.pth onto the optimal device (CUDA if available, otherwise CPU).
  • Vision Warmup: Loads MediaPipe Holistic Landmarker models and caches warm buffers to avoid first-frame latency spikes.
  • Graceful Teardown: Upon shutdown, releases MediaPipe native handles and cleans up background YOLO execution workers.

5.2. Telemetry & Request Tracing

Every incoming HTTP request is intercepted by custom middleware in main.py:88-106:

  • Generates a globally unique UUID4 correlation ID assigned to X-Request-ID.
  • Calculates execution duration via high-resolution monotonic timer: duration_ms = round((time.perf_counter() - t0) * 1000, 2).
  • Injects X-Response-Time-MS into the response headers for live client benchmarking.
